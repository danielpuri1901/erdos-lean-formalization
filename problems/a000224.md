## Plain statement

Count how many different remainders appear when you square every number modulo n; call it a. The claim: n squared leaves remainder 1 when divided by a times (a minus 1) exactly when n is an odd prime.

## Definitions

a(n) = number of distinct values of k^2 mod n for k=0..n-1 (a(1)=1). First 15 terms a(1..15) = 1, 2, 2, 2, 3, 4, 4, 3, 4, 6, 6, 4, 7, 8, 6. Claim for n>=2: (n prime and n != 2) <=> n^2 is congruent to 1 modulo a(n)*(a(n)-1). For a prime p, a(p)=(p+1)/2 so a(a-1)=(p^2-1)/4 divides p^2-1: the forward direction is easy; the open part is that composite n never satisfy it.

## Checked so far (Python, 2026-10-04, not a proof)

Python: n=2..200,000 exact via the multiplicative formula (validated against direct computation for n<=3000): 0 mismatches of the biconditional (Lean form with a(n)*(a(n)-1) as natural-number subtraction).

## Attack ideas

Search composites beyond 2*10^5 using multiplicativity of a(n) (cheap) for n with n^2 = 1 (mod a(a-1)); or prove it using the prime-power formulas for a(p^k).

## Risks and notes

Because a(n) has a closed formula, a counterexample hunt is cheap but likely empty; a proof needs case analysis over prime powers.
