## Plain statement

Is there a whole number x such that when you add up all the divisors of x and divide by x, the remainder is 5? The conjecture says no.

## Definitions

sigma(x) = sum of all positive divisors of x. a(n) = smallest x>=1 with sigma(x) mod x = n, or 0 if none exists. Claim: a(5)=0. a(0..15) = 1, 2, 20, 4, 9, 0 (conjectured none), 25, 8, 10, 15, 14, 21, 24, 27, 22, 16; so first 15 terms a(1..15) = 2, 20, 4, 9, 0, 25, 8, 10, 15, 14, 21, 24, 27, 22, 16 (a(18)=208, a(30)=841).

## Checked so far (Python, 2026-10-04, not a proof)

Python sieve of sigma: all x in 1..2,000,000: no x with sigma(x) mod x = 5; smallest x for residues 0..40 matches the list above (a(1)=2, a(2)=20, a(3)=4, a(4)=9, a(6)=25). No failure.

## Attack ideas

Write sigma(x)=k*x+5. k=1 means the proper divisors of x sum to 5, impossible (5 is untouchable by a short case check). For even k, sigma(x) is odd, so x must be a square or twice a square: search or rule out inside these sparse families; otherwise brute-force beyond 2*10^6 with a segmented sieve.

## Risks and notes

A counterexample, if it exists, is probably astronomically large; OEIS lists it as only conjectured. Lean def returns 0 when no x exists, so a(5)=0 is exactly 'no x' (x>0).
