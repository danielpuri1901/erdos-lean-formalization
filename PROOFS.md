# Proofs accepted by the checker

Each folder holds one Lean proof as it was when the checker accepted it: the frozen statement (`Challenge.lean`, taken with `type_of%` from the named formal-conjectures statement at commit `df3f12d7bd06`), the proof (`Solution.lean` and its modules), data files, and the session's notes.
The folders are copies for reading and archiving.
To build one, check out the commit in the table (also reachable as the tag `accepted/<id>`): it is a complete Lake project with the pinned `lake-manifest.json`.
The checker (`danielpuri1901/erdos-lean-checker`) rebuilt that commit from a clean checkout, replaced the agent's `Challenge.lean` with its own frozen copy, and ran Comparator in a sandbox; the linked run holds the log.
Every proof uses only the axioms `propext`, `Quot.sound` and `Classical.choice`.
The two Graffiti.pc proofs (`wowii19`, `wowii100`) came out of the open-problem sweep; both conjectures had been proved by other people before, see `docs/sweep.md`.
